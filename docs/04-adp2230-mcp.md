# 04 — ADP2230 MCP (instrumentación desde OpenCode)

El Digilent Analog Discovery Pro ADP2230 se controla directamente desde OpenCode mediante herramientas MCP. No requiere scripts manuales: podés generar señales, capturar con el osciloscopio, analizar espectros y más, todo desde lenguaje natural.

**Herramientas disponibles (8):**

| Herramienta | Función |
|---|---|
| `adp2230_info` | Info del dispositivo (nombre, serie, WaveForms) |
| `adp2230_awg_generate` | Generador de señales (AWG): senoidal, cuadrada, triangular, rampa, ruido, DC |
| `adp2230_oscilloscope_capture` | Osciloscopio 1 canal con trigger |
| `adp2230_oscilloscope_dual_capture` | Osciloscopio 2 canales simultáneos |
| `adp2230_spectrum_analyzer` | FFT / analizador de espectro |
| `adp2230_logic_analyzer_capture` | Analizador lógico 16 canales |
| `adp2230_pattern_generator` | Generador de patrones digitales 16 canales |
| `adp2230_gpio_control` | Control de pines DIO individuales |

## Prerrequisitos

- ADP2230 conectado por USB
- `pydwf` 1.1.19+ instalado en el entorno del MCP
- WaveForms 3.x instalado en Windows
- `usbipd` forwarding activo (desde WSL: `adp2230-attach`)

## Cómo está registrado

El servidor MCP (`mcp-servers/adp2230-server.py`) se registra en `~/.config/opencode/opencode.jsonc`:

```jsonc
{
  "mcp": {
    "adp2230": {
      "type": "local",
      "command": ["python", "/ruta/a/mcp-servers/adp2230-server.py"],
      "enabled": true
    }
  }
}
```

## Ejemplo 1: Generar una señal senoidal de 1 kHz / 1 Vpp

Desde OpenCode, simplemente pedilo en lenguaje natural:

> *"generá una señal senoidal de 1 kHz, 1 Vpp en el canal 1 del ADP2230"*

OpenCode invoca `adp2230_awg_generate` con estos parámetros:

```json
{
  "channel": 1,
  "waveform": "sine",
  "frequency_hz": 1000,
  "amplitude_vpp": 1,
  "offset_v": 0,
  "enable": true
}
```

**Respuesta del MCP:**

```json
{
  "channel": 1,
  "waveform": "sine",
  "frequency_hz": 1000.0,
  "amplitude_vpp": 1.0,
  "offset_v": 0.0,
  "enabled": true
}
```

La señal aparece inmediatamente en la salida **W1** (cable amarillo) del ADP2230.

**Para apagarla**, basta con pedir:

> *"apagá la señal del ADP2230"*

OpenCode llama a `adp2230_awg_generate` con `"enable": false`.

## Ejemplo 2: Capturar con el osciloscopio

```
> "capturá el canal 1 del scope a 10 MS/s, rango ±5V, trigger en flanco ascendente a 0.5V"
```

Parámetros que usa OpenCode:

```json
{
  "channel": 1,
  "sample_rate_hz": 10000000,
  "buffer_size": 8192,
  "voltage_range_v": 5.0,
  "trigger_source": "analog",
  "trigger_level_v": 0.5,
  "trigger_slope": "rise"
}
```

Devuelve estadísticas (Vmin, Vmax, Vpp, Vrms, Vmean) y una vista previa de las muestras.

## Ejemplo 3: Analizador de espectro (FFT)

```
> "hacé un FFT del canal 1 a 10 MS/s con 16384 muestras"
```

Devuelve frecuencia del pico, magnitud en dBV, y el espectro completo (frecuencia vs magnitud).

## Notas importantes

- **El AWG es persistente**: la señal sigue activa aunque el proceso MCP que la configuró termine. Para apagarla, usá `enable: false`.
- **Un solo proceso a la vez**: el ADP2230 no puede ser abierto por dos procesos simultáneamente. Si tenés WaveForms GUI abierto, cerrá el dispositivo ahí antes de usar el MCP.
- **Conexión física**: W1 (amarillo) es la salida del AWG. 1+/1- (naranja/blanco) son las entradas del scope.
- **Pydwf requiere enums**: si escribís scripts directos, no uses enteros crudos; usá `DwfAnalogOutFunction.Sine`, etc.
