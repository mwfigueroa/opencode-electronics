# 2026-08-02 (sixth entry) — Connecting the Rigol DS1054Z oscilloscope to the lab

**TL;DR:** Prepared the software stack so OpenCode can talk to a Rigol DS1054Z (SCPI). Two paths: **USB via usbipd + libusb (pyvisa-py)** and **LAN via raw SCPI socket (port 5555)**. LAN recommended; USB works but needs re-attach after replugs/reboots. Waiting for the physical connection to run the first `*IDN?`.

---

## Software stack (installed)

- `pyvisa` 1.16.2 + `pyvisa-py` (pure-Python VISA backend — **crucial**: the WSL2 kernel has `CONFIG_USB_TMC is not set`, so the `/dev/usbtmc0` kernel route is out; pyvisa-py talks USBTMC in userspace via libusb)
- `pyusb` + `libusb-1.0-0`, `zeroconf` (LAN/HiSLIP discovery)
- udev rule `/etc/udev/rules.d/99-rigol-usbtmc.rules`: Rigol VID `0x1AB1` → `MODE 0666` (no sudo needed per measurement)
- Already present: `sigrok-cli` (driver `rigol-ds`, SCPI backends TCP/serial/USBTMC), `usbipd-win` on Windows

## Path A — USB (USBTMC through usbipd)

```powershell
# Windows PowerShell AS ADMIN (one-time bind, then attach)
usbipd list                          # find "USB Test and Measurement Device" / VID 1AB1
usbipd bind --busid <BUSID>
usbipd attach --wsl --busid <BUSID>
```

```bash
# WSL
lsusb | grep -i 1ab1
python3 - <<'EOF'
import pyvisa
rm = pyvisa.ResourceManager('@py')
print(rm.list_resources())           # expect USB0::0x1AB1::0x04CE::<serial>::INSTR
s = rm.open_resource([r for r in rm.list_resources() if 'USB' in r][0])
s.timeout = 5000
print(s.query('*IDN?'))
EOF
```

Notes: `usbipd attach` must be repeated after unplugging/rebooting. DS1054Z PID is `0x04CE`.

## Path B — LAN (recommended)

1. Ethernet from the scope to the router; on the scope: **Utility → I/O → LAN**, note the IP.
2. From WSL (or Windows — both at once, no passthrough):

```bash
python3 - <<'EOF'
import pyvisa
rm = pyvisa.ResourceManager('@py')
s = rm.open_resource('TCPIP0::<SCOPE-IP>::5555::SOCKET')
s.timeout = 5000
print(s.query('*IDN?'))
EOF
```

```bash
# sigrok triggered capture example (2 channels, 1M samples)
sigrok-cli -d rigol-ds:conn=scpi/tcp:<SCOPE-IP> --channels CH1,CH2 --samples 1M -O csv
```

## What the agent can do once connected

- Identification/config: `*IDN?`, `:CHANnel<n>:SCALe`, `:TIMebase:SCALe`, trigger setup
- Measurements: `:MEASure:ITEM? VPP,CHANnel1` (Vpp, freq, rise time, etc.)
- Waveform capture: `:WAVeform:DATA?` → CSV/numpy for analysis (FFT, THD, ripple)
- Screenshots: `:DISP:DATA?` → BMP/PNG for visual checks in reports
- Long captures / protocol decode: `sigrok-cli` (I2C/SPI/UART decoders included)
