## Resumen

Sesión de prueba y depuración del MCP server para el Digilent Analog Discovery Pro ADP2230.

## Problemas encontrados y solucionados

### 1. AWG no generaba señal (`awg_generate`)

**Síntoma**: El MCP reportaba `"enabled": true` pero no salía señal por W1.

**Causa**: El `.pyc` cacheado en `__pycache__/` estaba stale. El código fuente (`adp2230-server.py`) ya usaba los enums correctos (`DwfAnalogOutNode.Carrier`, `DwfAnalogOutFunction.Sine`), pero el bytecode compilado no se actualizó.

**Solución**: Borrar `__pycache__/adp2230-server*.pyc` y reiniciar el MCP.

**Verificación**: Script directo con pydwf + enums funcionó correctamente:
```python
from pydwf.core.api.analog_out import DwfAnalogOutNode, DwfAnalogOutFunction
c = DwfAnalogOutNode.Carrier
awg.nodeEnableSet(0, c, True)
awg.nodeFunctionSet(0, c, DwfAnalogOutFunction.Sine)
awg.nodeFrequencySet(0, c, 1000.0)
awg.nodeAmplitudeSet(0, c, 3.3)
awg.nodeOffsetSet(0, c, 0.0)
awg.configure(0, True)
```

### 2. Pattern Generator usaba enum incorrecto

**Bug**: Línea 397 usaba `DwfDigitalOutIdle.Initial` → debe ser `DwfDigitalOutIdle.Init`.

**Fix aplicado** en `adp2230-server.py`.

## Comportamiento importante del ADP2230

- **El AWG retiene la última configuración en hardware** incluso después de cerrar el proceso que lo configuró. Para apagarlo hay que reconectar y llamar `awg.configure(0, False)`.
- **El device solo puede ser abierto por un proceso a la vez**. Si el script AWG está corriendo, el scope del MCP falla con `DstmIO failed ERC:3077`.
- **pydwf 1.1.19+ requiere enums**, no enteros crudos como en versiones anteriores.

## Script AWG funcional (respaldo)

```python
from pydwf import DwfLibrary
from pydwf.utilities import openDwfDevice
from pydwf.core.api.analog_out import DwfAnalogOutNode, DwfAnalogOutFunction

dwf = DwfLibrary()
with openDwfDevice(dwf) as device:
    awg = device.analogOut
    c = DwfAnalogOutNode.Carrier
    
    awg.nodeEnableSet(0, c, True)
    awg.nodeFunctionSet(0, c, DwfAnalogOutFunction.Sine)
    awg.nodeFrequencySet(0, c, 3000.0)
    awg.nodeAmplitudeSet(0, c, 1.0)
    awg.nodeOffsetSet(0, c, 0.0)
    awg.configure(0, True)
    
    input("AWG activo. Presiona Enter para detener...")
    awg.configure(0, False)
```
