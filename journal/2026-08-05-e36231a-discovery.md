# E36231A — LAN Discovery y Test Funcional

**Fecha**: 2026-08-05

## Contexto

La Keysight E36231A estaba catalogada en el roadmap como "physical test pending". Hoy se conectó físicamente a la red LAN del laboratorio y se realizó el discovery + test completo desde OpenCode.

## Discovery

1. **Escaneo de red**: se escaneó la subred `192.168.1.0/24` buscando puertos 80 (web), 111 (portmapper VXI-11), y 5025 (SCPI raw socket)
2. **Candidato**: `192.168.1.43:5025` respondió a `*IDN?` con:
   ```
   Keysight Technologies,E36231A,MY61005519,1.0.6-1.0.3-1.01
   ```
3. **Conexión VXI-11**: verificada vía pyvisa-py con el resource string `TCPIP::192.168.1.43::inst0::INSTR`

## Test funcional

| Paso | Acción | Resultado |
|---|---|---|
| 1 | `*IDN?` | Keysight Technologies,E36231A,MY61005519,1.0.6 |
| 2 | `*RST` + `VOLT 3.3` + `CURR 1.0` | Setpoint 3.300V / 1.000A ok |
| 3 | `OUTP ON` + `MEAS:VOLT?` | 3.3009V (error +0.03%) |
| 4 | `VOLT 5.0` + medición | 5.0006V (error +0.01%) |
| 5 | `VOLT 12.0` + medición | 12.0002V (error +0.002%) |
| 6 | `MEAS:VOLT:AC?` | ❌ No soportado (se usará ADP2230 scope AC coupling) |
| 7 | `VOLT 3.3` | 3.3040V ok |
| 8 | `OUTP OFF` | Apagado ok |

**Precisión de tensión: excelente** — errores < 0.03% en todo el rango 0-12V.

## Limitaciones encontradas

- `MEAS:VOLT:AC?` no implementado en este firmware (1.0.6). Para medición de ripple se usará el ADP2230 en modo scope con acoplamiento AC y filtro 20 MHz, que es más preciso de todas formas.

## Capacidades disponibles

Ver [skills/e36231a-psu/SKILL.md](../skills/e36231a-psu/SKILL.md) para referencia SCPI completa. Resumen de control:

### Control básico
- Set voltage (0-30V, 1mV resol.) / current limit (0-30A, 1mA resol.)
- Output ON/OFF
- Medición V/I con precisión DVM (5.5 dígitos)
- Reset y lectura de errores

### Protecciones
- OVP (sobrevoltaje) programable con detección de trip
- OCP (sobrecorriente) programable con detección de trip

### Funciones avanzadas
- **LIST mode**: secuencias arbitrarias de voltaje (rampas, pulsos, perfiles)
- **Battery simulation**: resistencia de salida programable (`OUTP:RES`)
- **Array measurement**: captura de V/I en el tiempo (`SENS:SWE`)
- **Remote sense (4-wire)**: compensación de caída en cables

### Cross-instrument (orquestación)
- **Load regulation**: E36231A + Prodigit 3310F (barrido V vs I)
- **Ripple + ruido**: E36231A + ADP2230 (scope AC coupling)
- **EMI bajo carga**: E36231A + Prodigit 3310F + N9000A CXA
- **Battery discharge**: E36231A (modo batería) + Prodigit 3310F (carga CC)
- **Power sequencing**: E36231A + ADP2230 scope dual (timing)
