# E36231A — LAN Discovery y Test Funcional

**Fecha**: 2026-08-05

## Contexto

La Keysight E36231A estaba catalogada en el roadmap como "physical test pending". Hoy se conectó físicamente a la red LAN del laboratorio y se realizó el discovery + test completo desde OpenCode.

## Discovery

1. **Escaneo de red**: se escaneó la subred `192.168.1.0/24` buscando puertos 80 (web), 111 (portmapper VXI-11), y 5025 (SCPI raw socket)
2. **Candidato**: `192.168.1.43:5025` respondió a `*IDN?` con:
   ```
   Keysight Technologies,E36231A,MY61005519,1.0.6-1.0.3-1.01
   ```
3. **Conexión VXI-11**: verificada vía pyvisa-py con el resource string `TCPIP::192.168.1.43::inst0::INSTR`

## Test funcional

| Paso | Acción | Resultado |
|---|---|---|
| 1 | `*IDN?` | Keysight Technologies,E36231A,MY61005519,1.0.6 |
| 2 | `*RST` + `VOLT 3.3` + `CURR 1.0` | Setpoint 3.300V / 1.000A ok |
| 3 | `OUTP ON` + `MEAS:VOLT?` | 3.3009V (error +0.03%) |
| 4 | `VOLT 5.0` + medición | 5.0006V (error +0.01%) |
| 5 | `VOLT 12.0` + medición | 12.0002V (error +0.002%) |
| 6 | `MEAS:VOLT:AC?` | ❌ No soportado (se usará ADP2230 scope AC coupling) |
| 7 | `VOLT 3.3` | 3.3040V ok |
| 8 | `OUTP OFF` | Apagado ok |

**Precisión de tensión: excelente** — errores < 0.03% en todo el rango 0-12V.

## Limitaciones encontradas

- `MEAS:VOLT:AC?` no implementado en este firmware (1.0.6). Para medición de ripple se usará el ADP2230 en modo scope con acoplamiento AC y filtro 20 MHz, que es más preciso de todas formas.

## Capacidades disponibles

Ver [skills/e36231a-psu/SKILL.md](../skills/e36231a-psu/SKILL.md) para referencia SCPI completa. Resumen de control:

### Control básico
- Set voltage (0-30V, 1mV resol.) / current limit (0-30A, 1mA resol.)
- Output ON/OFF
- Medición V/I con precisión DVM (5.5 dígitos)
- Reset y lectura de errores

### Protecciones
- OVP (sobrevoltaje) programable con detección de trip
- OCP (sobrecorriente) programable con detección de trip

### Funciones avanzadas
- **LIST mode**: secuencias arbitrarias de voltaje (rampas, pulsos, perfiles)
- **Battery simulation**: resistencia de salida programable (`OUTP:RES`)
- **Array measurement**: captura de V/I en el tiempo (`SENS:SWE`)
- **Remote sense (4-wire)**: compensación de caída en cables

### Cross-instrument (orquestación)
- **Load regulation**: E36231A + Prodigit 3310F (barrido V vs I)
- **Ripple + ruido**: E36231A + ADP2230 (scope AC coupling)
- **EMI bajo carga**: E36231A + Prodigit 3310F + N9000A CXA
- **Battery discharge**: E36231A (modo batería) + Prodigit 3310F (carga CC)
- **Power sequencing**: E36231A + ADP2230 scope dual (timing)

## Ejemplos de uso via OpenCode

### Ejemplo 1: Setpoint básico

> *"seteá la fuente en 9.3V, límite 100mA y encendela"*

```python
psu.write('VOLT 9.3')
psu.write('CURR 0.1')
psu.write('OUTP ON')
# Medido: 9.3007V, 0.12mA — error +0.008%
```

### Ejemplo 2: Perfil de glitching por pulsos

> *"creá un perfil de glitching que vaya de 8.2 a 11.7V, Ilim 100mA"*

Se generaron 6 pulsos con anchos variables (1, 2, 5, 10, 20, 50 ms), usando comandos `VOLT` directos desde Python:

```python
V_LOW, V_HIGH = 8.2, 11.7
pulse_widths_ms = [1, 2, 5, 10, 20, 50]
for width_ms in pulse_widths_ms:
    psu.write(f'VOLT {V_HIGH}')
    time.sleep(width_ms / 1000.0)
    psu.write(f'VOLT {V_LOW}')
    time.sleep(0.1)
```

**Resultados:**
```
Pulso   1ms → 11.494V (slew limit, no llega al target)
Pulso   2ms → 11.485V
Pulso   5ms → 11.423V
Pulso  10ms → 11.480V
Pulso  20ms → 11.459V
Pulso  50ms → 11.698V ✅ (target 11.7V alcanzado)
```

> **Nota**: la E36231A tiene slew rate finito (~100µF capacitor de salida). Pulsos < 50ms no alcanzan el target completo. Para glitching de precisión sub-ms se necesita un MOSFET externo o una fuente con modo fast transient.

### Ejemplo 3: Glitching aleatorio continuo

> *"hacé cambios aleatorios entre 8.2 y 11.7V cada 1 segundo"*

```python
V_MIN, V_MAX = 8.2, 11.7
while True:
    v_target = round(random.uniform(V_MIN, V_MAX), 3)
    psu.write(f'VOLT {v_target}')
    time.sleep(1.0)
```

**Resultados (10 ciclos):**
```
 1: Set 10.080V → Med 10.083V  | 71.2mA
 2: Set  8.251V → Med  8.255V  | 58.0mA
 3: Set 10.140V → Med 10.142V  | 71.3mA
 4: Set 11.036V → Med 11.037V  | 77.7mA
 5: Set  8.829V → Med  8.833V  | 62.0mA
 6: Set 11.102V → Med 11.103V  | 78.1mA
 7: Set 10.256V → Med 10.258V  | 72.2mA
 8: Set  9.360V → Med  9.362V  | 65.7mA
 9: Set 11.268V → Med 11.269V  | 79.4mA
10: Set 10.945V → Med 10.948V  | 77.2mA
```

La corriente varía proporcionalmente al voltaje (~58mA @ 8.2V → ~79mA @ 11.3V), indicando una carga resistiva de ~140 Ω conectada.

### Hallazgos sobre LIST mode

Se intentó usar `LIST:VOLT` + `LIST:DWEL` para secuencias precisas en hardware, pero el trigger no respondió correctamente (la E36231A quedaba en `LIST:STEP AUTO` ignorando los dwell times). Para perfiles con timing de milisegundos, los comandos `VOLT` directos desde Python son más confiables. El modo LIST queda pendiente de debuggear con el manual de programación.
